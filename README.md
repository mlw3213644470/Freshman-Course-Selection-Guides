# Freshman-Course-Selection-Guides

武汉大学选课经验网页：《选课经验：少走弯路，排好第一份课表》。

核心原则：**只做选课指导，不给具体数据和链接**。页面只写判断方法、核对步骤和该去问谁，不列课程名单、学分、给分、通过率，也不跳转外部地址。

## 页面结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 入口页：访问根地址时自动跳转到 `首页.html` |
| `首页.html` | 封面页：以武汉大学牌楼照片为首屏，站点的第一屏，提供选课准备、课程比较、课表安排与常见问题入口 |
| `guide.html` | 指南首页：蜿蜒路线串联五个板块，可直达「选前准备」 |
| `prep.html` | 选前准备：读懂毕业要求、整理清单、检查选课条件 |
| `course-info.html` | 课程信息：对照清单、打听问题模板、红黄绿提示 |
| `schedule.html` | 课表安排：放固定课 → 填自选 → 检查整周 → 备选方案 |
| `after.html` | 选后调整：立即核对、开课复盘、调整前确认 |
| `faq.html` | 常见问题：4 组场景、15 条折叠问答 |
| `学长抢课秘籍.html` | 学长抢课秘籍：页面骨架，内容待补充 |

板块之间用「上一步 / 下一步」按钮按顺序串联；指南首页与页脚的导航可跳到任意板块。页头「常见问题」右侧另有「樱下选课」（跳到 `课程信息.html`）和「学长抢课秘籍」两个入口。

访问根地址（开发服务器 `/` 或部署后的站点根目录）时，`index.html` 会立即跳到封面页 `首页.html`；封面页上的「查看选课指南」在页内定位到三步概览，`prep.html` 等指南页的导航与「← 返回封面」可回到封面或指南首页 `guide.html`。

「樱下选课」（`课程信息.html`）是独立的通识课探索页：樱花课程树、MBTI 兴趣助手、教师推荐与课程图鉴，页头左上角有「← 返回指南」跳回本站首页。

## 开发

需要 Node.js 20+。

```bash
npm install     # 首次运行安装依赖
npm run dev     # 开发服务器，默认 http://localhost:5173
npm run build   # 构建到 dist/
npm run preview # 预览构建结果
```

## 实现说明

- `src/guide.css`：全站样式（珞珈绿 + 米白纸质），含首页路线与移动端时间轴布局。
- `src/guide.js`：注入页头页脚导航、标记当前板块、问答「全部展开／收起」、滚动渐显。
- `vite.config.js`：多页构建入口（上面 8 个页面）。

## 旧版文件

`课程信息.html`、`课程数据.js`、`教师推荐数据.js`、`global.css`、`style.css`、`pages/`、`assets/` 为早期实验页面，保留未改动，**不参与打包**；其中 `课程信息.html`、`课程数据.js`、`教师推荐数据.js` 与 `global.css` 由构建脚本原样复制到 `dist/`，供「樱下选课」入口使用。
